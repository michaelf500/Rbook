# Security Policy

## Supported Versions

This repository does not currently publish numbered releases. Security fixes (if needed) are applied only to the latest commit on the default branch.

| Version / Branch | Supported |
| ---------------- | --------- |
| `master`         | ✅        |
| Older commits    | ❌        |

If/when tagged releases are introduced, this table will be updated to reflect which release lines receive security updates.

## Reporting a Vulnerability

Please do **not** open a public GitHub Issue for security-sensitive reports.

### Preferred reporting channel (private)
Use GitHub’s **private vulnerability reporting** for this repository:
- Go to the repository **Security** tab
- Select **Report a vulnerability**
- Provide the details below

### What to include
To help triage quickly, please include:
